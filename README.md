# VitrineVirtual

Landing page experimental para uma experiência visual de apresentação de um espaço de reserva natural.

## Sobre o projeto

O VitrineVirtual explora uma composição visual minimalista construída com HTML e CSS, utilizando imagens e elementos gráficos para criar uma apresentação centrada em uma peça visual principal.

O projeto pode ser usado como exemplo de **composição visual, prototipação de landing pages e experimentação de layouts para web**.

## Tecnologias

- HTML5
- CSS3
- Google Analytics

## Estrutura

```text
VitrineVirtual/
├── img/
├── index.html
├── layout.png
└── layout2.png
```

## Como executar

Abra o `index.html` no navegador ou utilize Live Server.

## Objetivo

Exercício de desenvolvimento front-end voltado para composição de layout, uso de imagens como elementos de interface e construção de uma página visual de apresentação.
